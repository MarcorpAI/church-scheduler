# ServeFlow v2: Sunday Service Testing Scenario

Follow these steps to test the new Live Control and Planning features.

### **Step 1: Plan the Service**
1.  **Create New**: Go to **New Service**.
2.  **Use Template**: Select a template (like "Sunday Service") to see the list populate automatically.
3.  **Rearrange**: Drag and drop any item to change the order.
4.  **Add Item**: Add a "Special Announcement" and set it to `5 minutes`.

### **Step 2: Review & Go Live**
1.  **Click Go Live**: A review dialog will appear.
2.  **Set Mode**: Toggle to **"Auto-Advance"**.
3.  **Set Buffer**: Set a `10 second` buffer.
4.  **Confirm**: Click "Start Live Service".

### **Step 3: Manage Live**
1.  **Watch the Timer**: Notice the "Standby Warning" flash when 30 seconds are left.
2.  **Add Time**: The service is running late? Click **+1m** or **+30s** to instantly add time to the current item.
3.  **Skip Ahead**: If you need to skip an item, scroll down to the "Live Run Sheet" and click **Skip To** on any upcoming item.
4.  **Automatic Switch**: Let an item finish. The system will wait for your 10-second buffer and then automatically start the next item.

---
**What to look for:**
- Does the countdown feel accurate?
- Do the buttons (+30s/Skip) react immediately?
- Is the "Auto-Advance" working smoothly with the buffer?
